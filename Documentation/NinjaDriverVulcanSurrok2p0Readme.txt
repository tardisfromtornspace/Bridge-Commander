Readme file for Surrok class cruiser for Bridge Commander
Model v2.0  created by NinjaDriver  (BCN Forums)

Texture created by Dante   (BCN Forums)

http://home.attbi.com/~mattwhite/bcdownloads.html

BC-Mod Installer is required to install this mod.
Run BC-Mod Installer and extract the Surrok.BCMod file to your Bridge Commander directory
Play BC, it can't get much simpler than that.

This is V2.0 of this mod.  The model has been changed to more reflect the CGI model and the texture has been completely redone by Dante.  He did an excellent job of capturing the detail and coloration of the CGI model.


If you would like to get the .max file for the model or the .psp texture files with all layers, then please
contact me on the BCN Forums.  If you would like to do any texture modifications then feel free to do so, just
post a pic somewhere where I can see it...

Have fun.

DJcubes J-Class MVAM Upgrade Readme
--------------------------
Description: This upgrades the Mvam plugin for the J Class transport.
It:

Includes reintergration, where the ship reverses to pick up the cargo,
Changes the camera to a front view,
Zommes the camera out a bit,
Made the ship more likely to dump its cargo. (Computer controlled)
--------------------------
Installation: Copy the Script folder to your bridge commander directory
--------------------------
Bugs Known: You can only reintergrate once
